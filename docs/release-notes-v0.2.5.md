# OpenConnect Android v0.2.5

## English

- Refreshed the Android UI around a Telegram-like visual language with cleaner spacing, lighter typography, and a more iPhone-inspired overall feel
- Redesigned the home, thread detail, and settings screens to reduce clutter and keep the most important actions easier to reach on mobile
- Grouped assistant execution details under the related response, added expandable process summaries, and opened each step in a dedicated dialog for full inspection
- Tightened the pending approval dialog so long commands no longer stretch the whole page; approval details now scroll inside the card while approve and reject actions stay visible
- Enabled edge-to-edge rendering and updated system bar styling to better match the new full-screen interface
- Bumped the Android app version to 0.2.5 and continue shipping an installable debug APK because the repository does not include a release keystore

## 中文

- 将 Android UI 重构为更接近 Telegram 的视觉语言，整体间距更干净、字号更轻，整体气质也更接近 iPhone 风格
- 重新设计首页、线程详情页和设置页，减少臃肿感，让移动端最常用的操作更容易触达
- 把 assistant 的执行细节挂到对应回复下方，支持折叠执行过程摘要，并可通过弹框查看单步完整内容
- 收紧待审批弹窗布局，长命令不再把整页撑开；审批详情会在卡片内滚动，批准和拒绝按钮始终可见
- 启用了 edge-to-edge 渲染，并同步调整系统栏样式，让全屏界面和新的 UI 更一致
- Android 版本号提升到 0.2.5；由于仓库未包含 release keystore，本次仍提供可直接安装的 debug APK
